How to run live data
1. Clone and start sofascore_scraper (Docker or ssc serve).
2. Follow NFL: ssc follows add tournament 9464 --name NFL --sport american-football --seasons last:1
3. Enable standings if needed and run ssc sync
4. Enter the API base above (default http://127.0.0.1:8000).
